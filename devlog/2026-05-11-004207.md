## Refactored sort_key sourcing from Loro's internal tree position, eliminated shadow meta key, and unified chord ops

**Context**

The Phase 3.2 work had introduced a redundant `sort_key` meta key in Loro to track block positions—but Loro already maintains fractional indices internally via `LoroTree::fractional_index()` in the exact same hex format. This was architectural debt: two sources of truth for the same ordering information.

**What happened**

- Discovered `LoroTree::fractional_index(target)` exposes Loro's internal positioning in the shared `loro_fractional_index` format; eliminated the shadow meta key entirely
- Refactored `read_block_from_tree` to read position exclusively from the tree, removing the legacy meta-key fallback
- Deleted `LoroBackend::update_block_sort_key`; replaced inbound `apply_*` callers with a new `apply_sort_key_hint()` that uses `update_block_position` (tree positioning) instead
- Introduced `find_position_for_sort_key_hint` as a shared free helper (sibling scan + fractional-index comparison) used by both registry and inbound paths
- Refactored `move_block` chord op to call a new `BlockOperations::move_to_position` helper, consolidating the (compute neighbors → `gen_key_between` → retry loop) sequence
- Verified with targeted unit tests (19/19 block ops, 5/5 registry, 28/28 loro_backend) and combined PBT smoke (504s) — both `general_e2e_pbt_sql_only` and `general_e2e_pbt` Full pass

**Decisions**

- Deferred `join_block`, `split_block`, `rebalance_siblings` chord-op unification: they need richer anchor types than `after_id`-only; the registry intercept already handles them correctly, so the refactor can wait
- Kept `gen_key_between` live in `holon-core` for now (chord ops that haven't migrated still call it); full retirement is a clean follow-up once all positioning routes through tree moves

**Status**

Phase 3.4 fully landed — sort_key is now sourced exclusively from Loro's tree position, inbound sync routes through position-based moves, and the shared sibling-scan logic is factored out. The codebase no longer shadows Loro's fractional index.
