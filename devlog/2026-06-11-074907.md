## Debugging Missing Row in Virtualized GPUI List

A row that should be visible in a virtualized list was never painting, manifesting as both a deterministic regression and a flaky intermittent bug during property-based testing.

**What happened**

- Investigated a "missing row" bug spanning two stacked root causes in the concurrent memory-reduction session's Phase 2 (virtualized `gpui::list`).
- **Root cause 1 (deterministic):** `scroll_entity_into_view` was silently no-oping. It looked up the list shell by `stable_cache_key()` on a fresh `snapshot_reactive` tree, whose new `ReactiveView` instances never matched the rendered shell's cache key. Fixed by walking the panel cache and querying each shell via new `ReactiveShell::visible_index_of`, which also fixed a raw-vs-visible index bug under tree collapse.
- **Root cause 2 (flaky):** Off-screen windows only commit frames via per-input forced refresh; async follow-ups (variant swap, post-split insert) that lose the race never paint. Fixed by making the scroll RPC refresh the window and scoping a frame pump to bounds/widget-kind/window-focused-editor waits (rejecting a global 100ms pump that matched user-activity blur contamination).
- Fix landed as jj change `mopnwnoy` in the gpui-pbt-speed worktree; persisted regression now passes (`all 1 case(s) passed`). None of the four original failure faces recurred across validation runs.
- Idle-gated validation batch completed with exit 0; full details in `devlog/2026-06-11-gpui-pbt-missing-row-rootcause.md` and memory file.

**Challenges**

- **Cache key mismatch across tree snapshots:** Took iterative probing with `lldb` sampling the reactive shell iteration at render time to reveal that fresh snapshots create new `ReactiveView` instances that never match rendered shell keys. Solved by querying shells already in the panel cache.
- **Frame starvation in off-screen windows:** Distinguishing between timing and window focus required frame-pump scoping; a naive global pump created different contamination patterns matching user-activity blur signatures.
- **Test contamination from foreground input:** Idle-gated validation harness filters runs where `end-idle < wall-time`; users typing during tests invalidates the run.

**Status**

Fix committed and persisted regression green; three overlapping worktrees (this one, pbt-no-loro-slices, memory-reduction) require reconciliation before merge. Idle validation clean.
