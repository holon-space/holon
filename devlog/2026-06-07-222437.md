## TestQuery Extended to Layout-Traversal Queries; Stopgap Guard Replaced

The `!has_user_index_org()` blanket proxy that prevented block interactions on custom layouts was replaced with a faithful two-axis rendered-set model, making `TestQuery` the single source of truth for layout query semantics across all variants.

### What happened

- **Extended `TestQuery`** with `QuerySource` dimension (`AllBlocks` / `DirectChildren{context}` / `DescendantsOfAny{min,max}` / `FocusRootDescendants{region,max}`) covering all layout-query forms in PRQL/SQL/GQL with matching `compile_layout_for` emitters and `recognize()` inverse.
- **Built equivalence PBT** (`query_equivalence_pbt.rs`) to prove `TestQuery::evaluate()` semantics match the real backend across all three query languages — it **caught a real bug**: GQL `CHILD_OF*` returns source-typed blocks (unlike PRQL stdlib `children`/`descendants` which filter them). Fixed `evaluate()` accordingly.
- **Rewired all 5 layout generators** to emit through `compile_layout_for` instead of hardcoded strings.
- **Replaced the stopgap** in `reference_state.rs`: removed the blanket `blocks_render_interactively()` checks and the `!has_user_index_org()` drag proxy. Wired all 9 block-interaction transitions (6 generic + 3 fully-qualified) + drag to gate on `rendered-set ∩ template-interactivity` computed from the active layout's `TestQuery::rendered_block_ids()`.
- **Verified end-to-end**: Query-equivalence PBT (3/3 GREEN), Loro gate (25s GREEN), Turso `sql_only` gate (193s GREEN), traced sample confirms `SplitBlock` fires non-vacuously through the new gate.

### Challenges

- **GQL `CHILD_OF*` semantics divergence**: The equivalence PBT revealed that GQL transitive closure includes source-typed blocks, but PRQL/SQL stdlib tables don't. Caught before it could cause flakes; fixed in `evaluate()`.
- **No live backend to empirically verify**: Built a de-risk PBT instead of hand-reading query equivalence, which paid off immediately.

### Decisions

- **Per-variant faithful modeling over simplification**: Traversal (rendered-set) and template-op (interactivity) are independent axes; the model preserves current behavior exactly for all 5 layout variants + default.
- **De-risk-first with PBT**: Rather than sink hours into one architecture, validated query semantics against the real backend before wiring the removal.

**Status**: All block-interaction transitions and drag now gate on faithful rendered-set + template-op axes; stopgap removed. Both gates + equivalence PBT green; Turso Full variant running.
