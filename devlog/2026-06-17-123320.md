## Retiring the Reference Model Editor Fixtures

Completed F2 Stage 2: migrated all reference-model test oracle code off hand-rolled `FixtureRef`/`EditorModel` fixtures onto the real `ReferenceState` primitives, deleting 239 lines of duplicate logic and fixing an editor caret boundary bug in the process.

**What happened**

- **R2 (editor primitive consolidation):** Refactored `ReferenceState::ActiveEditor` to delegate `type_chars`, `delete_backward`, `move_cursor` to the production `holon_frontend::editor_caret` module. Deleted hand-rolled `insert_str`/`char_indices` logic; fixed a `move_cursor` mid-codepoint bug via `clamp_boundary`. Added `editor_caret` unit-PBT with three multibyte Unicode properties (caret always on boundary, insert/delete round-trip, clamp always legal). Baseline: 19→29 tests green.

- **Stage A (non-editor oracle sites):** Built `subsystem_seed.rs` helpers — `seed_ref`, `assert_ref_seeded` (fail-loud parity), `run_with_seeded_ref` (runtime ownership pattern). Migrated their/sql/memory positive slices + all 7 catch invariant tests off `ref_map(FixtureRef)` onto real `ReferenceState`. Catch tests verified still RED (same divergence root cause). 39 tests green.

- **Stage B (editor proptests):** Added `seed_ref_with_editor` helper. Migrated memory editor static/proptest/E0b + `editor_caret`/`editor_text` catch tests off `EditorModel`/`FixtureEditorRef`. Commit-roundtrip proptest now drives production `InProcEditorSut` write cap so both reference and SUT normalize identically. 10 tests green.

- **Cleanup:** Deleted `FixtureRef`, `ref_map`, `full_ref_map`, `FixtureEditorRef`, `editor_ref_map`, `EditorModel` (239-line net reduction, zero remaining code references).

**Challenges**

- **Runtime-drop-in-async panic:** `ReferenceState` owns `Arc<tokio::runtime::Runtime>`, which panics if dropped on an async executor. Fixed by `run_with_seeded_ref`: creates/drives the `ReferenceState` in a sync scope, passes clones into the async test loop, and moves the final drop to a std thread. Per-tick evaluations use `rt.block_on()` from the proptest's sync context.

- **Proptest dev-dep compilation:** Adding `proptest` to `editor_caret.rs` triggered a 55-process rebuild. Mitigated by parallelizing spec reading during the build.

**Decisions**

- **Full-qualified `proptest::sample::select`:** Resolved ambiguity with local imports by fully qualifying the path rather than adding a `use` alias, keeping imports minimal.

- **Parity via identity ID mapping:** `ReferenceState` seed produces exact block/wiring identity to `FixtureRef`, confirmed via neutral `Wiring` and `Block::set_sequence` inspection — no scheme drift needed.
