## MCP-Proxy++ and Context Brokerage for Holon

**Context**: Explored whether Holon could move beyond routing MCP calls to act as a "context broker"—leveraging its persistent graph, reactive cells, and org-file substrate to collapse the media break between human knowledge and agent working memory.

**What happened**:
- Identified three core advantages: implicit argument resolution (agent uses focused block as context), personalized tool ranking via PRQL over block history, and result grounding (tool outputs become blocks with backlinks).
- Sketched the context-bloat solution: a meta-tool (`holon_tool_search`) that indexes MCP schemas on-demand, ranked by usage + project scope, avoiding full schema preload.
- Designed dynamic tool discovery as a subscription (not one-shot), diffing new tools into the block graph and updating schemas reactively.
- Resolved the human-agent interaction improvement: shared editing surface (org file = conversation), approval prompts quoting context blocks, one-keystroke result review.
- Spawned research agent to compare competitors (Obsidian MCP, Notion, Letta, Anytype, Khoj, OpenHands); confirmed no other system has Holon's reactive+CRDT+MCP stack.

**Decisions**:
- Lead with killer demo (provenance + re-executable source blocks + reactive supervision) as the marketing artifact, not a separate project.
- Reframe "Holon AI" as LLM-budget tier (€15–25/mo) rather than note-taking tier, bundled with Backup + Connect.
- Drop near-term Holon Teams; solo dev motion better suits prosumer/freelancer wedge (Todoist first, then JIRA/Linear/Gmail).

**Status**: Three vision documents written to `/docs/Vision/`; monetization strategy corrected and filed to `/docs/Strategy/MonetizationAddendum.md`. Path to €300K/yr target clarified: ~1,800 subs by Y3 via 4% conversion on 45K free users.
