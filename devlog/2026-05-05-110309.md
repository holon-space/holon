## Refactor

`frontends/tui/src/app_main.rs::enter_pressed` had three branches mixed
with engine dispatches. The pure decision is now `decide_enter_action`:

```rust
enum EnterDecision {
    Nothing,
    DispatchSelectable(OperationIntent),
    EnterEdit(EditableTarget),
}

fn decide_enter_action(registry: &RenderRegistry, idx: usize) -> EnterDecision {
    if idx == NO_FOCUS { return EnterDecision::Nothing; }
    let Some(region) = registry.selectables.get(idx) else { return EnterDecision::Nothing; };
    if region.kind == SelectableKind::Selectable {
        return match region.intent.clone() {
            Some(intent) => EnterDecision::DispatchSelectable(intent),
            None => EnterDecision::Nothing,
        };
    }
    match region.editable.clone() {
        Some(target) => EnterDecision::EnterEdit(target),
        None => EnterDecision::Nothing,
    }
}
```

The `navigation.editor_focus` intent shape is now in
`editor_focus_intent_for(block_id: &str) -> OperationIntent` so a test
can assert it without booting the engine.

`enter_pressed` is now a thin shell: lock → `decide_enter_action` →
match → dispatch via the engine. The chord-resolution-stale-focus
regression that the editor_focus dispatch guards against is documented
inline (preserved comment).
