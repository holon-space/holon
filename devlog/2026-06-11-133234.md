## Fixed `#+TODO:` keyword removal and `EntityUri` parsing landmine

**Context:** Two critical bugs were blocking the layout PBT from stabilizing: org metadata properties weren't being cleared on rewrite, and synthetic block IDs with `::` separators were silently forking writes to SQL instead of Loro.

**What happened:**

- **Task #2 root-caused** — `#+TODO:` swallow lived at *both* storage boundaries, not in the sync controller. `prepare_update` merged properties with insert-only semantics; `LiveDocumentManager::update_metadata` didn't diff removals; Loro's adapter merged instead of replacing.
- **Added removal sentinel** — `Value::Null` convention (matching existing `update_block_fields`) in SQL's `prepare_update`; `prepare_create` drops Nulls. `LiveDocumentManager` now diffs cached doc and emits Null for removed keys.
- **Loro side fix** — new `LoroBackend::replace_block_properties` method for exact-set writes (empty set clears). Adapter switched from `update_block_properties` (merge) to `replace_block_properties`.
- **Task #1 root-caused** — `EntityUri::from_raw("root-layout::src::0")` parsed the head as a valid RFC 3986 URI scheme, so `resolve_to_tree_id` returned None for nodes **present** in the Loro tree. Content writes then silently took the SQL fallback. One-line fix: reject parses whose path starts with `:`.
- **Validated** — 3 new boundary tests; all gate matrix sweeps green (layout both twins, general_e2e full/sql_only 63–64s, split+loro 13/13). Pinned capture replays clean.
- **Squashed into main** — rebased 10 descendants, zero conflicts.

**Challenges:**

- **Dual-boundary property merging** — required coordinating fixes across SQL (`prepare_update`, `prepare_create`) and Loro adapter (`replace_block_properties` new method) with consistent Null sentinel semantics.
- **URI parsing ambiguity** — `::` in block IDs looked like valid scheme separators; fix discriminates by checking whether a parsed path would start with `:` (impossible in real URIs, the signature of a bare ID with separators).

**Status:** Both bugs fixed and validated green. Layout PBT still has pre-existing finding (link-mark family, 8-case sweep) — triaged for later investigation alongside inherited split_full case.
