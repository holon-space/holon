## Gherkin fixtures as happy-path PBT inputs

We explored using Gherkin `.feature` files as a new fixture format — hand-authored happy-path scenarios that replay through the same state machine harness as JSON regression fixtures, gaining coverage from global invariants plus positional `Then` assertions.

**What happened:**

- Identified that `holon_pbt_core::fixture::replay()` already exists as the right replay engine, treating precondition-skips as inspectable outcomes rather than silent failures — avoiding the staleness-rotting problem that plagued the unmaintained cucumber path
- Validated the block addressing contract: content blocks authored with org `:ID:`s are addressable verbatim; document containers use `ref-doc-N` (creation order), fully author-controlled and deterministic
- Confirmed async settling happens *before* invariant checks (full CDC drain → matview quiescence → settling barrier), so positional `Then` assertions read stable state by default without needing polling logic
- Found that `Fixture<T, I>` has an unused second type param that's the right home for positional assertions, and the `gherkin` parser crate is already a transitive dependency through cucumber
- Discovered the step-matching logic can be authored fresh against the current `E2ETransition` enum rather than inheriting stale assumptions from the old `app_workflow.feature`

**Challenges:**

- The current `declare_pbt_slice!` wires a worse reimplementation (`run_fixture_dir`) that silently skips precondition failures, masking staleness; we need to migrate slices to use `replay()` instead
- Global invariants are macro-generated token streams without a reusable free function, so the harness must hand-write the `check_invariants` closure per-slice
- The `Then` vocabulary will need its own assertion type (separate from `E2ETransition`), mapping block-addressing to existing SUT accessors (`block_content`, `focus`, `sorted_children`)

**Decisions:**

- Use `gherkin` crate as a direct parser (not transpiling to JSON), keeping `.feature` files as hand-authored source-of-truth with fresh step matchers against current `E2ETransition` variants
- Target `SqlOnly` variant first (Full is upstream-blocked on Turso); old `app_workflow.feature` retires later
- Reuse `holon_pbt_core::fixture::replay()` rather than extending `run_fixture_dir`, fixing the silent-skip blocker as a side effect

**Status:** Ready to implement. Plan is: (1) migrate one slice (`split_block_content_pbt`) to `replay()` + hand-written invariant closure as proof point, (2) wire `GherkinFixtureSource` parser + step matchers, (3) add positional `Assert` vocabulary and `FixtureStep` enum, (4) expand Scenario Outlines with Examples substitution.
