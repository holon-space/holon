## V2 Paint-Proof Gate & B3 Loro Render Fork

**Context:** The handoff required proving the async-snapshot-to-UiEvent bridge works (V2 gate), then implementing b3's snapshot-aware `render_entity` fork with a Turso-free `ProfileResolver`. A parallel session was reshaping storage, so the task required verifying current code state before planning.

**What happened:**

- **Phase 0 — V2 gate (headless proof):** Built `loro_ui_watcher.rs` test harness proving `FrontendSession::watch_ui` can emit `UiEvent::Structure` + `UiEvent::Data` from a pure-Loro `BlockSnapshot` without Turso. The downstream reactive-engine consumption path is already proven by existing unit tests (`data_event_adds_rows`) and backend-agnostic PBTs (`gpui_ui_pbt`).

- **Phase 1 — B3 render fork (implementation):** 
  - New module `crates/holon/src/api/loro_ui_watcher.rs` implements `loro_watch_ui`, deriving a real `view_mode_switcher` (profile-based) from snapshot children instead of a placeholder.
  - Lifted `collection_render_from_profile`, `wrap_in_query_source_switcher`, `parse_render_source_content` from `BlockDomain` to `pub(crate)` and threaded them through both Turso and Loro paths—no parallel copy.
  - Built Turso-free `ProfileResolver` via `with_type_profiles` + `create_default_registry()`; test confirms built-in collection variants are available.
  - Block-to-row mapping uses canonical `block.to_entity().fields` (resolves the plan's fidelity risk).
  - Forked `FrontendSession::watch_ui` on `block_query()` with new resolver field; Turso path untouched.

**Decisions:**

- **Snapshot-children block-info read:** Query-source and render-source children are present in `BlockSnapshot`, making them reconstructable without Turso (avoids querying matviews).
- **Turso-free resolver seeding:** `ProfileResolver::with_type_profiles` + empty `LiveData` gives a resolver whose cache holds built-in profile variants; no Turso coupling.

**Status:** Phase 0 (V2 gate) and Phase 1 (b3 fork) complete and green. `FrontendSession::watch_ui` now renders profile-derived `view_mode_switcher` + child rows from pure-Loro snapshots. Workspace check clean; 11 tests passing (new `loro_ui_watcher` 2/2, `no_turso` 2/2, b1 regression 7/7). Part (a) (backend-parametric runner + slice binary) deferred to next session.
