## Scoped Multi-Agent Work Candidates for Parallel Worktree Execution

**Context:** The codebase has accumulated uncommitted PBT improvements and scattered code-health violations. Rather than a single focused session, there's an opportunity to spawn independent worktree branches for parallel execution on disjoint file ownership, provided the PBT stack lands first as a clean base.

**What happened:**
- Surveyed 23 crates, 9 frontends, and architecture docs across the Holon codebase
- Fanned out investigation across code health (28 archlint violations), PBT test harness maturity, render builders, and replication readiness
- Consulted planning vault notes on "Dogfooding & Agents" and MVP priorities
- Ranked work by parallelizability and file-ownership disjointness rather than raw leverage
- Documented eight ultracode/worktree candidates with pros/cons and merge-safety constraints

**Key decisions:**
- **Commit the dirty PBT stack first (Step 0).** Worktrees fork from committed refs; the ~36 uncommitted files in the main checkout won't be visible to branches, creating merge conflicts if slices touch overlapping areas like `holon-integration-tests`.
- **Prioritize disjoint crate ownership over raw value.** Single-writer replication is higher-leverage but a poor fan-out target; code-health and render builders partition cleanly into independent crates.
- **First batch: W1+W2+W3** — `holon-frontend`, `holon-api`/`holon-loro`, and `frontends/tui` archlint fixes + render builders. Each runs `cargo check` + `archlint` in isolation; merges in any order.

**Challenges:**
- Shared `arch-baseline` regeneration — serialize via "fix violations in each slice, run `just arch-baseline` once at merge time"
- Catalog expansion is append-only to avoid conflicts in `catalog.rs`/`mod.rs`
- W3/W4 (TUI/Dioxus frontends) must only *consume* render contracts from W1, never modify them

**Status:** Ranked candidates documented in `holon-pkm/Projects/Holon/Ultracode Investment Candidates.md` with merge rules; ready to spawn first parallel batch after PBT stack lands.
