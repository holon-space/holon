## Typed `_routing_doc_uri` Field & Phantom-Loro Startup-Seed Fix

**Context**: Phase 3.7 introduced typed `Event.position_after_block_id`. This session extended that pattern to `routing_doc_uri`, then discovered and fixed a race condition where blocks were appearing in Loro before CDC events arrived during startup.

**What happened**:
- Confirmed all Phase 3.7 unit tests pass; triaged 5 pre-existing test failures on parent commit
- Mirrored typed-field pattern exactly: added `Event::routing_doc_uri: Option<String>`, transport key `ROUTING_DOC_URI_PAYLOAD_KEY`, and wired producer/consumer boundary at `SqlOperationProvider`
- `TursoEventBus` now flushes the typed field into payload on INSERT; `parse_row_change_to_event` lifts it back; `OrgMode` consumer reads `event.routing_doc_uri` instead of underscore-prefixed payload string
- Added archlint rule `routing_payload_key` to prevent future payload-key pollution (excludes canonical const def in `event_bus.rs`)
- **Root-caused phantom-Loro-exists flake**: directed instrumentation revealed `seed_loro_from_persistent_store` was creating blocks from persistent store *after* `OrgFileWatcher`'s initial scan had written them to SQL, causing `apply_create` to bypass CDC processing
- Fixed by filtering seed query with `LEFT JOIN events WHERE e.id IS NULL` — skips blocks still awaiting CDC, lets raw seed-defaults (`seed_default_layout` panels) through normally

**Challenges**:
- Test suite timeouts initially; killed stalled run and confirmed 3 failures pre-existed on parent commit
- Mid-test reproducer passed but didn't surface the bug — needed startup-specific instrumentation to isolate the race
- Pre-existing archlint violations in helper functions required minimal bare-`_` param cleanup before landing

**Decisions**:
- Deferred full-PBT mid-test phantom-Loro variant verification to next session; startup race fix is high-confidence and unblocks roadmap items 2-4
- Kept write-side traces at `error!` level; downgraded read-side trace to `debug!` to avoid production log spam

**Status**: Items 1a (startup race), 5 (typed routing_doc_uri), and 7 (archlint rule) LANDED. Item 1b (mid-test PBT variant) requires verification run in next session; pending that, items 2-4, 6 unblock for gate flip and downstream work.
