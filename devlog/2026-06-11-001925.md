## Completing Fixed-ID Contract & Root-Causing Layout Override Bugs

The layout-override axis-4 finding was resolved by pinning a fixed-ID contract in the generator and ref model, then surfacing and fixing four production bugs in the handoff layer.

### What happened

- Implemented the fixed-ID contract: generator index arms now emit `:ID: root-layout`; ref model gates default-layout seeding, journals focus, and drawer state on prod freshness
- Root-caused layout override silently failing: user index.org with random root ID was ignored while default layout still seeded (old Flutter discovery API assumption)
- Fixed `update_parent_id` in sut_check_invariants.rs: unchanged-parent writes were incorrectly triggering `tree.mov`, causing silent sibling reordering; now a positional no-op with regression test
- Fixed content cell binding: hardcoded `CONTENT_RAW` container caused index.org swaps to silently lose updates; cell now selects container by node's content type
- Fixed `source_language` writes: were bypassing Loro (SQL-direct authority fork); now routes through `LoroBackend::set_source_language`
- Fixed boot race: seed vs. index.org scan competed; deterministic now via freshness check of `:ID: root-layout` marker in filesystem port

### Challenges

- **Fractional index tie-breaking**: `enable_fractional_index(0)` allowed equal indexes; concurrent moves were non-positional. Root cause found by instrumenting every Loro tree move and dumping actual fractional index values.
- **Silent content loss**: cell lens hardcoded container type, polluting source nodes. Required tracing through content writes to surface that `cell.set` mutations weren't persisting.
- **Concurrent session interference**: absorbs silently dropped guard lines mid-fix; restored them and added regression unit test to catch future occurrences.

### Decisions

- **Fixed-ID vs. migration path**: pinned generator to emit `root-layout` rather than attempt backward compatibility, simplifying the contract
- **Deterministic freshness check**: gated default-layout seeding on explicit `:ID: root-layout` in index.org (filesystem check) rather than Loro content scan, avoiding race conditions
