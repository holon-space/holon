## Senior Review → Implementation: Holon Dependency Graph Hygiene

A senior developer reviewed a multi-stage refactoring plan to decouple holon's dependency graph and validate its assumptions against the codebase. The review found three falsified hypotheses and uncovered a missing gate on session query paths. Rather than shelving the findings, implementation began immediately.

- **Hypothesis validation before coding**: Tested seven implicit assumptions against actual line refs (EntityUri keying, orgmode confinement, ViewKind isolation, etc.); three falsified (popup_query expressibility in PRQL/GQL, from_raw guessing, read-path divergence on tombstones), all recorded as explicit tasks
- **Part A implementation (Stages 1–6)**: Moved `BuilderServices` trait and three impls to holon-api; extended `QueryEngine` for typed capabilities (`search_link_candidates`, `block_content_by_id`); rewired holon-frontend session factories and reactive shell to consume capabilities instead of raw SQL
- **Discovered vestigial dependency**: `loro` in holon-frontend had zero usage — confirmed and removed during refactor
- **Session query path rediscovery**: Stage 2b inserted post-review: `FrontendSession::query_and_watch` now folds into the session factory constructor, catching an inference gap that archlint couldn't name
- **Library surgery**: Deleted SQL link-provider; replaced assembly constructors with capability-typed `from_parts()`; relocated session factories from holon-frontend to new holon-app modules
- **Updated consumers**: gpui, tui, mcp, and integration-tests now import from holon-app instead of holon-frontend; Part A code-complete with workspace compiling clean

**Challenges**: rust-analyzer stale diagnostics in feature-gated PBT files during refactor; pre-existing test failures (7 on holon, 7 on baseline) confirmed unrelated to changes. Verification ladder queued: fast unit slices first, then full sql_only gate without parallelism cap.

**Status**: Part A (Stages 1–6) code-complete and compiling. Part B (read-model verification, archlint gate, trait relocation stretch) queued after baseline gate completes.
