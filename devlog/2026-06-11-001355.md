## Reactive-Settle Follow-Ups & Missing-Row Bug Localization

**Context:** Continuing from a prior reactive-settle refactor, this session completed eight follow-up tasks (exit-code trust, window-focus invariant, zombie-editor fix, perf budgeting, TUI reactivity, justfile recipes) and then investigated a pre-existing deterministic gate failure where a block row vanishes from the painted panel despite being present in all data/query/ViewModel layers.

**What happened:**

- Fixed the exit-0 trap on macOS: `cx.quit()` was terminating before the post-`app.run()` panic re-raise could propagate. Added bg-thread failure stashing and explicit exit 101 on quit; verified with forced and real failures both exiting 101.
- Implemented `inv-window-focus-matches-engine-focus` invariant (31 registry guard tests pass): added `focused` field to `RenderedElement`, wired it from `ElementInfo`, registered Strict/ProperlySetup.
- Fixed zombie-editor race: `spawn_focus_binding` now blurs the window when focus authority leaves a still-focused editor, so dropped keystrokes land safely.
- Added `HOLON_PBT_SUPERHUMAN_INPUT=1` (keystroke pacing disable) and `HOLON_PBT_STEP_BUDGET_MS` (per-transition timing enforcement in both replay loops).
- Wired TUI `GeometryProvider::changed()` to wake paint-quiescence waiters via `TuiGeometry` in `install()`.
- Added `just pbt` / `just pbt-no-loro` recipes; killed stale-binary trap by building and running the exact reported binary.
- Investigated missing-row gate failures: extended layer-attribution diagnostics (SQL → matview → ViewModel → BoundsRegistry) and found all data layers correct, 25/25 rows present—only painted window lacks the row. Blur fix and block-sync refactor both exonerated 3/3.

**Challenges:**

- **Exit-0 masking:** Handoff's "×4 green" validation was the exit-0 trap reading gate failures as passes; fix revealed gates were never green.
- **Concurrent jj churn:** Main rewritten twice by parallel sessions; half-landed Loro compaction broke `crates/holon`. Wrote missing `export_delta_or_full_snapshot` (delta with warn-disclosed full snapshot for stale peers) and made `save_counter` an `Arc<AtomicU64>`.
- **Stale-binary variants:** Feature-graph changes caused `cargo build` to write new hashes while old binaries kept running; `just pbt` extraction from cargo JSON is the antidote.

**Decisions:**

- Step budget as dedicated env var (not boolean `HOLON_PERF_BUDGET`) because threshold is per-runner, not global.
- TUI's 240ms stability window left poll-based (cursor-blink commits would wake `changed()` constantly).
- Blur fix default-on with kill-switch `HOLON_GPUI_BLUR_ON_FOCUS_LEAVE=0` for regression testing.
