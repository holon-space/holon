## Renamed task-blocker terminology to `requires` and wired typed-field parsing

The `BLOCKED-BY` drawer property wasn't populating the `task_blockers` junction table due to three compounding mismatches: missing typed field on `Block`, type-erased drawer dump, and edge-field partition demanding exact-case keys with `Value::Array` shape. Instead of patching the symptom, we remodeled blockers as a first-class `requires` field symmetric to how `tags` works.

**What happened**

- Added `pub requires: Vec<String>` to `Block` struct with full round-trip support (`block.rs:286`)
- Updated org parser to extract `:REQUIRES:` drawer entries (case-insensitive, comma/whitespace-separated) into `block.requires` instead of leaving them in generic properties (`holon-org-format/src/parser.rs:398`)
- Updated org renderer to reinject `REQUIRES` on round-trip (`models.rs:712`)
- Modified `build_block_params` to emit `requires` as `Value::Array` for edge-field partitioning (`block_params.rs`)
- Renamed SQL schema: `task_blockers` → `block_requires`, matview `task_blocking_edges` → `block_requirement_edges`, columns `blocked_id`/`blocker_id` → `block_id`/`required_id` (`schema_modules.rs:129`, SQL definitions)
- Updated `EdgeFieldDescriptor` routing for the new schema and all downstream consumer code
- Migrated 28 existing `:BLOCKED-BY:` entries across 7 org files in holon-pkm to `:REQUIRES:` notation
- All 70 holon-org-format tests + 4 edge-field integration tests pass

**Challenges**

- Initial perl-based migration merged multi-line drawer entries (e.g., `:BLOCKED-BY:` + `:Effort:` folded together). Fixed with a follow-up Python pass that properly preserved drawer structure.
- Parser initially only accepted comma-separated values; extended to accept whitespace-separated (org-edna convention) as well.

**Status**

Fully implemented and tested. Live engine became unresponsive on raw SQL after processing 7 concurrent file modifications; awaiting reconnect to verify `block_requires` junction now populates correctly and Now.org query properly filters on the typed field.
