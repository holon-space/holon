## Phase 3: Extended Generator Implementation

Extended the PBT harness to cover Unicode, nested headings, and multi-line content by implementing env-gated `HOLON_PBT_EXTENDED_GEN` generator expansions.

**Context:** The original generators were ASCII-only and single-level, masking unit confusion and parser gaps. Phase 3 adds realistic content diversity while maintaining test determinism and axis orthogonality.

**What happened:**

- Implemented axis-1 content diversity: `regular_file` with Unicode emoji, `type_chars` with multi-byte sequences, `peer_edit` across content types, `bulk_external_add` with varied headlines
- Created extended-gen slice file with skip-path verification (0.014s disclosed)
- Discovered and fixed **byte-vs-char three-way confusion**: generator produced byte indices `0..=len`, ref sliced at raw bytes (panicked mid-codepoint on emoji), SUT pressed `right` per *byte* instead of char. Fixed via char-boundary generation + precondition validation + byte→keystroke conversion against pre-transition text
- Discovered and fixed **parser gap in link extraction**: `[[text]]` content had Link mark stripped in ref model but not normalized in generator output. Fixed by running `extract_inline_marks` in `normalize_content_for_org_roundtrip`
- Implemented axis-2 nesting: multi-level heading trees with per-parent sibling ordering constraints; two-pass parent deduplication in `SplitBlock` and `BulkExternalAdd` to keep axes orthogonal
- Ran extended sweeps: axis-1 alone (32 cases), combined (16 cases), axis-2 deep (32 cases) — all green

**Challenges:**

- **Timeout contention:** Extended-gen slice exceeded nextest's 2-min default; added 20-min override to `extended_gen_pbt` for long-test handling
- **Attribution complexity:** Initial axis-1 failures spanned three codepaths (generator, ref, SUT); isolated by replaying each sub-arm (`link`/`empty`/`unicode`/`#+`) in separate runs to pinpoint `[[text]]` divergence cleanly
- **Shared-repo churn:** Concurrent sessions rewrote main mid-Phase-3; worktree's working copy held Phase 2–3 diffs intact; no merge conflicts but coordination needed

**Decisions:**

- **Char-boundary enforcement:** Rather than bounding generator to safe indices and masking the bug, added explicit char-boundary checks to catch hand-edited captures and document the invariant
- **Axis orthogonality:** Nesting axes use true-sibling filtering for `requires` edges; parent deduplication is two-pass to avoid accidental coupling between content and structure

**Status:** Phase 3 complete — axis-1 (content) and axis-2 (nesting) both verified green across 32-case deep sweeps; two harness bugs fixed, one parser bug quarantined; default gates remain green (split/loro guards + sql_only baseline unaffected).
