## Item 3 & 4 Handoffs: Origin-Aware Block API + Read-Side Ordering

**Context:** Two handoff tasks needed completion: extending the block read-side with sibling/child navigation methods, and threading `EventOrigin` through the block-create API so file-driven Org events pass the inbound gate instead of dropping.

**What happened:**

- **Item 4 (read-side):** Extended `BlockOrdering` trait with `prev_sibling`, `next_sibling`, `first_child`, `last_child` methods. Implemented on both `SqlBlockOperations` (cache filter+sort) and `MemStore` (existing `sorted_children`). Converted `BlockQueryHelpers` defaults to delegate through the new trait methods, consolidating read logic.
- **Item 3 (origin-aware API):** Added `execute_operation_with_origin(entity, op, params, origin)` to `OperationProvider` trait. Refactored `SqlOperationProvider::publish_event` to accept and thread `origin` through all three dispatch arms (set_field/create/update). Migrated `LiveDocumentManager::create` to emit `EventOrigin::Org` instead of the default `Other("sql")`.
- **Gate regression test:** Tightened `org_origin_events_pass_the_gate_as_apply` to assert `drop_count == 0` after startup—the new baseline for production Org flow.
- **Verification:** Full baseline GREEN across holon-core (47/47), loro_sync_controller (16/16), integration gates (3/3), PBT (2/2 @ 508s), and real-window GPUI UI PBT (46/50 transitions exercised).

**Decisions:**

- **Scope boundary:** `action_watcher` (DSL) and MCP `add_subtask` still route through `HolonService`, not `OperationProvider` directly. Migrating them requires separate plumbing and policy (gate whitelisting for new origins). Deferred as documented open follow-ups.
- **Default delegation:** The trait default for `execute_operation` now ignores origin and calls through unchanged—allows gradual migration of call sites without breaking legacy paths.

**Status:** Both Item 3 and Item 4 complete and verified. Gate-disabled production wiring now passes zero events at the inbound gate for the file-driven Org flow.
