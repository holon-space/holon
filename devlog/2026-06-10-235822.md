## Memory audit: where Holon copies/consumes memory unnecessarily

Three parallel audits covered the data→render pipeline, the GPUI widget layer, and caches/retention. Baseline: 1000-block document ≈ 1 MB of content.

### Eight major copy/retention hotspots identified

1. **Main document panel has no row virtualization** — materializes all N blocks as persistent `RenderEntityView` entities with 10–15 cached elements each (~10–50 MB @1000 blocks), every row pre-painted every frame, images decoded regardless of viewport. Largest widget-count lever.
2. **`LoroProjection` copied whole document ~5× per keystroke** — deep-cloned on read, cloned into `put_base`, entire store cloned for JSON persist, full-document disk write on every wake. **Fixed this session.**
3. **`LoroBackend.event_log` grows unbounded** — every mutation appended with full block content; new subscribers clone entire log as replay backlog. Subscribers silently dropped when channel full (fail-loud bug).
4. **EditorView/InputState never evicted** — one per ever-focused block, holding content + undo + layout caches, cached under row-level key with no wipe path.
5. **Matviews never dropped during session** — one Turso IVM view per block ever watched; only `drop_stale_views` at startup.
6. **Full tree re-interpretation per CDC row change** + **O(N²) `RenderContext` clones** in static row pipeline (~16 MB transient per pass @1000 rows).
7. **~6 simultaneous resident copies of block set** — Loro doc, projection base map + JSON sidecar, Turso, two `LiveData` mirrors, widget props, per-editor copies. Several slimmable to `Arc`.
8. **Per-frame/per-event churn** — `ElementInfo` stages full document text twice as owned Strings, `eprintln!` on every sync, whole `RenderExpr` trees as cache keys, per-event diagnostics snapshot all rows.

### What happened

- **Base store fixes** (`sync_base_store.rs`, `loro_sync_controller.rs`): snapshots now `Arc`, `after` moved instead of cloned, no-op projection passes skip base write + disk write. Eliminates ~3 document-sized copies + serialize + disk write per keystroke and idle wake.
- **CDC echo suppression** (`reactive.rs`): row cells use `set_neq`; identical CDC echoes no longer fan out into per-row re-interpretation.
- **No whole-`RenderExpr` clones** for `is_loading`/Structure-event comparison (compare under `lock_ref`).
- **Per-event diagnostics** gate behind `tracing::enabled!` (cheap `ReactiveRowSet::len()` path added).
- **Phase 0 landed**: `eprintln!` → `tracing::trace!` in backend sync; `ProviderCache` sweeps dead-`Weak` entries on insert.
- **Phase 1a landed**: editor eviction via focused→unfocused latch on `RenderEntityView`, evicts `EditorView` + undo + layouts; guard prevents focus-move races; kill-switch `HOLON_EDITOR_EVICT=off`.
