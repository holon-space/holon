## Refactored editor caret arithmetic and collapsed data-container duplication

Addressed the duplication audit: extracted pure caret primitives from `HeadlessEditorMirror::handle_keystroke` into a shared module, unified byte↔codepoint conversion (was triplicated inline), and collapsed `ModelBlock` in both test slices to use production `Block` directly.

**Context:** The PBT found that `InMemEditorComponent` was re-implementing production's caret math, weakening the differential oracle. Meanwhile `ModelBlock` was an unnecessary data-container copy. Plan: extract primitives, rewire both callers to a single source of truth, and simplify the test models.

**What happened:**
- Created `holon-frontend/src/editor_caret.rs` — pure functions for insert/delete/move/clamp/byte-to-codepoint, zero dependencies, guarded by 12 unit tests
- Rewired `handle_keystroke` (4 arms + 3 inline conversions) to call shared primitives instead of hand-rolling caret math
- Collapsed `InMemEditorComponent` to delegate `type_chars`/`delete_backward`/`move_cursor` through `editor_caret` instead of copying logic
- Removed `ModelBlock` struct and `to_blocks()` helper from both `memory_slice` and `loro_slice`; models now hold `Vec<Block>` directly

**Key decisions:**
- Kept `EditorModel` (`Vec<char>` / codepoint oracle) unchanged — it's a genuine differential check, not a duplication smell
- Scoped extraction to *pure arithmetic* (caret position, byte↔codepoint); engine-coupled operations (`apply_text_op`, structural intent dispatch) remain in `handle_keystroke` and stay E2E-only, as intended

**Status:** Full plan executed — editor caret now has a single source of truth, `ModelBlock` duplication removed from both slices, all 28 proptest cases + unit tests green, zero warnings. Ready to commit.
