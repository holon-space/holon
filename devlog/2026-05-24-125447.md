## CDC Quiescence and JoinBlock Precondition Fixes

**Context:** The `general_e2e_pbt` test was failing on intermittent CDC race conditions and chord-dispatch precondition gaps. A prior fix (`wait_for_blocks_synced`) was present but the SqlOnly variant still raced, suggesting the barrier wasn't complete.

**What happened:**

- Reproduced the CDC race: a late `bulk-0-0` Update event landing after all settle barriers, triggering `[("all_blocks", 1)]` assertion failure
- Traced the event to an OS file-watcher tail: a benign one-shot re-projection (identical structural data) arriving ~150ms after test barriers closed, then settling
- Reframed the fix: the old `assert_cdc_quiescent` treated *any* late activity as fatal churn; the real problem was distinguishing a settling convergence tail from genuine non-settling churn
- Rewrote the quiescence assert with a budget: allow up to 150ms of post-settlement tail activity, fail only if activity *persists* (genuine add/remove churn)
- Investigated a JoinBlock chord-dispatch failure on `block:journals` (a page); found the precondition gap: pages can't be backspace-joined
- Added `is_page_block()` guard to JoinBlock precondition, matching existing guards in move_up/move_down

**Challenges:**

- Initially hypothesized the late event came from the controller's 100ms `poll_tracked_files` fallback; trace disproved this (zero poll re-ingests observed)
- Correctly attributed the event to FSEvent latency, but the real insight was that the event *was* observed within the existing 50ms window—the assert just wrongly escalated a benign tail to fatal failure
- Attempted a secondary fix (assign append-sequences to new bulk blocks before canonical sort) based on incorrect assumption that SUT ordering was authoritative; reverted it to avoid masking real bugs

**Decisions:**

- Preserved the real-churn detector (fail on persistent add/remove activity) while eliminating false positives from settling tails
- Kept the invariant `inv-live-children-match-ref` as-is (designed to catch SUT sort_key projection bugs) rather than patch the ref to hide a deeper org-parser convergence issue

**Status:** CDC race and JoinBlock-on-page fixed and verified; SqlOnly passes the fixes but hits a pre-existing `inv-live-children-match-ref` sort_key convergence bug (deep block-sync rework territory) that was masked by earlier failures.
