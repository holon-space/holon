# Handoff: Option E-solid Risk De-risking Spike

**Date:** 2026-07-03 (session continuation)  
**Context:** Evaluating whether Option E (model the op ids via lamport proxy) can replace adoption-based oracle verification without the brittleness risk.

## The Question

Can a **shadow peer mesh** (reference-side Loro docs) with **clock synchronization at `AddPeer`** reproduce the SUT's exact tie-break order and text interleaving, despite having a completely different primary doc history?

- **Why it matters:** If yes, E-solid eliminates all SUT→Ref data copying (including adoption) and gives strict-equality invariants with the strongest possible teeth. If no, the mechanism breaks and we fall back to Option D (equivalence predicates).
- **The residual risk:** Reading one scalar (`global_doc.lamport` height) per `AddPeer` to pad shadow peers' clocks. This is a SUT→Ref read, but it's a **non-observable coordinate** (like UUID sync), not data. Need to confirm this distinction holds under scrutiny.

## Spike Plan

Write a deterministic Loro-only test that:
1. Creates a **real peer mesh** scenario (concurrent creates, text edits, merges) with synthetic peer ids
2. Records the **SUT's lamport clock at each step** (queried via `get_change().lamport`)
3. Builds a **shadow mesh** replaying the exact same ops but with clock-padding from those records
4. Asserts that **tie-break order and text content match exactly** between SUT and shadow at each step

**Location:** Spike test module at end of `multi_peer.rs` (or `loro_backend.rs` if feature-gating is a blocker)

**Success criteria:**
- Shadow and SUT agree on sibling order (no permutation needed)
- Shadow and SUT agree on text interleaving (no multiset fallback)
- No adoption, no equivalence classes — strict equality throughout

**Failure modes to catch:**
- Clock padding insufficient (tie-break still flips) → need a better sync strategy
- Op-shape divergence (shadow ops encode differently) → E is fundamentally unsound
- Loro internals too opaque to replicate → fall back to D
