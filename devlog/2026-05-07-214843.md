## FU-9 PBT Regression Infrastructure for Pin/Unpin Semantics

Implemented property-based testing (PBT) infrastructure for the pin/unpin sidebar operations, which had regressed in earlier refactors. The work involved extending the reference state model, adding new transition types, and fixing pre-existing SQL parsing bugs discovered during validation.

**What happened**

- Extended `ReferenceState` in `reference_state.rs` with `pinned_blocks` and `open_pin_entry` fields to track sidebar pin state
- Rewrote `expected_focus_root_ids()` to compute focus roots based on navigation history + pinned blocks, replacing a flawed heuristic
- Updated three existing transitions (`navigate_home.rs`, `navigate_focus.rs`, `click_block.rs`) to maintain the new reference state fields
- Implemented two new transition types: `pin_block.rs` and `unpin_block.rs` with corresponding `SutHandle` methods on `E2ESut`, registered in the macro invocation
- Fixed SQL parsing bug in `crates/holon/src/storage/mod.rs:36`: the statement splitter was breaking on `;` inside `--` comments, truncating Phase C/D's `navigation.sql` mid-table-definition
- Fixed `LiveData<FocusRoot>` watch query to filter `WHERE root_id IS NOT NULL`, preventing panics on home rows during test validation

**Challenges**

- SQL semicolon splitter was naive and comment-unaware. Rewrote it as a stateful character iterator that skips semicolons in `--` line comments.
- Home rows (NULL `block_id`) in the `focus_roots` materialized view were breaking the test-side FocusRoot reader. Added NULL filtering to the SELECT query (matching production GQL behavior).
- Invariant 7 (`current_focus` cursor check) panics on CDC lag instead of using the same truth-check + WARN pattern as other invariant checks—documented as FU-14, blocking full test completion.

**Decisions**

- Skipped budget adjustments for this pass—only affect `--features otel-testing` runs outside the standard test path; documented as follow-up.
- Fixed bugs on test-side rather than matview SQL to avoid side effects on production query logic.

**Status**

FU-9 infrastructure complete and compiling clean; architecture tests confirm new transitions registered correctly. Three pre-existing bugs (FU-12, FU-13, FU-14) uncovered and partially fixed; FU-14 (invariant 7 CDC lag handling) remains open and blocks `general_e2e_pbt` completion.
