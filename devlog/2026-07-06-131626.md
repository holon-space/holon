## Fixed Missing `PrecondSpec` Import in holon-petri

The `holon-petri` crate failed to compile due to unresolved type references in the Petri-net engine integration.

**What happened**

- Attempted to run `cargo run -p holon-gpui` and encountered three `E0433` errors: "cannot find type `PrecondSpec`"
- Errors occurred at three call sites in `crates/holon-petri/src/lib.rs` (lines 1012, 1028, 1063) where `PrecondSpec::Exact()` was used
- Added missing import: `use holon_engine::PrecondSpec;` at the top of the file
- Build succeeded after fix

**Challenges**

- The type was re-exported from `holon_engine` but not imported into the local scope — a residual issue from a refactoring of the Petri-net engine where the import statement was accidentally removed or never added to the migrated code

**Status**

`holon-petri` now compiles cleanly. Ready to proceed with `cargo run -p holon-gpui`.
