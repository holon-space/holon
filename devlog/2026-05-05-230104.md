## Fixing Org Renderer Matview Lag (Devlog 110315 v5)

The org renderer was emitting stale org files despite passing the watermark gate, causing "Org file diverged from reference" failures in the SqlOnly PBT.

**What happened:**

- Audited all render-emitting paths in `di.rs` (`on_block_changed`, `re_render_all_tracked`, `on_file_changed`) — watermark gate logic was sound
- Investigated `CacheBlockReader::get_blocks` and discovered it read `SELECT * FROM block` (a CDC matview), which lags behind the underlying `block_raw` by an unbounded propagation window
- Root cause: renderer snapshots were stale — same race class as devlog inv10d
- Switched `load_all_blocks_with_hydration` in `crates/holon-orgmode/src/di.rs:239` to query `block_raw` directly using a correlated subquery against `block_tags`
- Removed dead-coded matview helper; one consolidated method is now the only path
- Silenced two pre-existing archlint hits at lines 850 and 1047 with ALLOW comments
- SqlOnly PBT re-run: **0 "Org file diverged" failures** (fix verified), but 21 panics surfaced at `sut.rs:3547` — a separate, previously masked CDC-watch bug with wrong block IDs

**Status:** Original devlog 110315 issue is closed. New ticket handed off for `sut.rs:3547` watch divergence (likely reference over-emitting virtual entities the SUT never persists). Ready to commit.
