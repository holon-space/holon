The growth is cargo's own: `target/debug/build/holon-app/<hash>/out/` holds a 238 MB linked test binary plus its object units (~229 MB per dir); holon-app has 34 test targets but 878 hash dirs (81 GB) because different gate invocations (`-p` sets, `--features` shapes) unify workspace features differently, so each shape mints a new metadata hash (6 distinct dependency counts × 2 profile hashes measured) and the old dirs are orphaned forever; cargo never GCs them.
